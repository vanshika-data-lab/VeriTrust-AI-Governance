2. Relational Table Schemas

TABLE: use_cases

Primary AI System Registry
Column Type Constraint Description
id INTEGER PK AUTOINCREMENT Unique AI use case identifier
name TEXT NOT NULL Name of AI system under governance review
industry TEXT NOT NULL BFSI, Healthcare, HR & Employment, Aviation & Aerospace
purpose TEXT NOT NULL Operational objective and functional scope
autonomy_level TEXT NOT NULL Advisory, Human-in-the-Loop, Human-on-the-Loop, Fully Autonomous
data_types TEXT NOT NULL JSON serialized array of data classifications (PII, Financial, Biometric)
affected_population INTEGER DEFAULT 1000 Total scale of individuals impacted
impact_tier TEXT NOT NULL Low, Medium, High, Critical

TABLE: assessments

Master Evaluation & Risk Tier Record
Column Type Constraint Description
id INTEGER PK AUTOINCREMENT Unique assessment ID
use_case_id INTEGER FK use_cases(id) Associated use case reference (ON DELETE CASCADE)
overall_risk_score REAL NOT NULL Composite weighted risk score (0.0 - 100.0)
risk_level TEXT NOT NULL Low Risk, Moderate Risk, High Risk, Critical Risk
eu_ai_act_category TEXT NOT NULL Minimal Risk, Limited Risk, High-Risk (Annex III), Unacceptable Risk
executive_summary TEXT NOT NULL Executive compliance audit conclusion & statutory synthesis

TABLE: dimension_assessments

10 Granular Governance Dimensions (1:10 Relational Breakdown)
Column Type Constraint Description
id INTEGER PK AUTOINCREMENT Unique dimension record ID
assessment_id INTEGER FK assessments(id) Parent assessment reference (ON DELETE CASCADE)
dimension_key TEXT NOT NULL data_gov, privacy, bias_fairness, oversight, explainability, etc.
risk_score REAL NOT NULL Normalized dimension risk score (0.0 - 100.0)
findings TEXT NOT NULL Statutory and architectural audit findings
mitigating_controls TEXT NOT NULL JSON serialized array of concrete engineering controls

TABLE: evidence_sources

6-Tier Legal & Regulatory Citations
Column Type Constraint Description
id INTEGER PK AUTOINCREMENT Evidence citation ID
assessment_id INTEGER FK assessments(id) Parent assessment ID (ON DELETE CASCADE)
source_tier TEXT NOT NULL Law / Regulation, Regulatory Guidance, Industry Standard, Research, Vendor, Web
title TEXT NOT NULL Canonical title (e.g. EU AI Act Regulation 2024/1689)
citation_text TEXT NOT NULL Specific section, article, or recital reference
url TEXT DEFAULT '' Direct URL to official statutory authority portal
reliability_score REAL DEFAULT 0.9 Tier credibility weight (0.50 - 1.00)
