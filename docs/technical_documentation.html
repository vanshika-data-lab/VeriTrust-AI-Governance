1. Executive Summary & Questionnaire Alignment

Core Mission

VeriTrust AI addresses the critical enterprise need for repeatable, mathematically grounded AI risk assessments that comply with international statutory frameworks (EU AI Act, GDPR, NYC LL144, ECOA, NIST AI RMF) without relying on black-box LLM scoring.

  • Deterministic Non-Black-Box Scoring: Utilizes a calibrated 10-dimension mathematical matrix ensuring 100% reproducible results for regulatory auditability.
  • 6-Tier Source Classification: Categorizes evidence into Law, Guidance, Standards, Research, Vendor Info, and Web Commentary.
  • Live "Surprise Record" Ingestion: Dynamically processes novel AI systems submitted by evaluators in real time.
  • ACID Relational Storage: Persists all evaluations in normalized SQLite tables with cascading deletes and audit trails.
  • 100% Free & Open-Source: Operates locally with zero paid API keys or commercial dependencies.

4. REST API Specification

GET    /api/health                  # Service health & version status
GET    /api/use-cases               # Retrieve all evaluated AI use cases
POST   /api/assess                  # Ingest & dynamically assess a novel AI system
GET    /api/assessments/{id}        # Detailed 10-dimension assessment with 6-tier citations
DELETE /api/use-cases/{id}          # Remove use case & cascade delete assessments
GET    /api/sources                 # Query 6-tier knowledge base by term or tier
GET    /api/analytics               # Aggregate portfolio statistics & risk ratios
GET    /api/export-report/{id}      # Downloadable JSON compliance report payload
