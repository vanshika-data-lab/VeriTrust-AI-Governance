3. Layer-by-Layer Architectural Responsibilities

1. Presentation Layer React 18

Responsive, reactive dashboard with executive risk analytics, live test forms, and statutory evidence visualizers.

  • Dynamic "Surprise Record" Ingestion
  • 10-Dimension Visual Risk Meters
  • 6-Tier Statutory Citation Drawer
  • One-Click Audit Report Export

2. API Gateway Layer FastAPI

Asynchronous REST API with strict Pydantic payload validation, CORS middleware, and sub-millisecond response times.

  • POST /api/assess (Dynamic Evaluation)
  • GET /api/use-cases & /api/analytics
  • GET /api/sources (Knowledge Search)
  • GET /api/export-report/{id}

3. AI Intelligence Layer Deterministic

Weighted mathematical scoring engine ensuring 100% reproducible and transparent risk calculations.

  • 10 Discrete Scoring Dimensions
  • EU AI Act Risk Categorization
  • 6-Tier Reliability Weighting
  • Statutory Mitigation Control Synthesis

4. Persistence Layer SQLite 3

ACID-compliant relational storage storing use cases, dimensional scores, citations, and knowledge base items.

  • 3NF Normalized Table Schema
  • Cascading Deletion Rules
  • Zero-Latency Local File Store
  • Automated Initial Seed Migrations

5. Research & Citation Layer 6-Tier

Dynamic research retriever indexed with canonical statutory legal codes, regulatory guidance, and international standards.

  • Tier 1: EU AI Act, GDPR, NYC LL144
  • Tier 2: FTC, EEOC, FDA, FAA Guidance
  • Tier 3: NIST AI RMF, ISO/IEC 42001
  • Tier 4-6: Stanford CRFM, Vendor & Web
